Сессия 2026-09-17: агент одним сообщением дал понятие frontmatter, модель
Note и алгоритм функции. Пользователь запутался («Frontmatter — это ты
показал, как выглядит, или я должен что-то сделать?») и попросил «давай
поэтапно». После разбивки на шаги «сейчас пишем только модель» работа
пошла ровно.

Второе наблюдение: операции со строками/списками (split/join/срезы)
пользователь «делал миллион раз, но не запоминал». Сработало объяснение
словами без кода как схемы из трёх действий («разрезать → найти границу →
склеить»), с правилами-лакмусами (левая граница среза входит, правая нет;
join вызывается на разделителе). Код он после этого написал сам почти
верно.

**Why:** понятие и задание в одном сообщении сливаются — непонятно, что
из этого «прочитать», а что «сделать». Схема действий запоминается,
набор методов — нет.

**How to apply:** одно сообщение = один шаг с явной пометкой «сейчас
делаем X». Понятие вводить непосредственно перед шагом, где оно
применяется, а не заранее пачкой. Когда пользователь просит «объясни
словами без кода» — давать схему действий и лакмусы, метод-имена можно,
сниппеты нет. Дополняет [[explain-from-reasoning]].
